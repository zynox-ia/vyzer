# Drizzle 0.45 with versioned SQL migrations

Database access uses Drizzle ORM on the stable 0.45 line, not the v1 release candidate; the upgrade to v1 happens as its own change after v1 is stable. Migrations are SQL files generated by `drizzle-kit generate`, reviewed and committed, and applied by the deploy before the API starts; `drizzle-kit push` is never used against a shared or production database. Prisma was rejected because its current major version is still a release candidate.
