# Radius

Direção atual: **raio zero**. Todos os tokens resolvem para 0, exceto `full`, usado só onde a forma carrega significado: radio, ícones de status, avatar e thumb do switch.

Use o seletor **Raio** do toolbar (0, 2 ou 4 px) para comparar: a escala inteira acompanha (`xs` = metade, `sm` e `md` = base, `lg` = 1,5×, `xl` = 2×, `2xl` = 3×).
