# Radius

Direção atual: **reto** (preset `0`). A política de raio já está pronta para mudar sem tocar em componente nenhum: troque o preset no toolbar (**Raio**) e a interface inteira acompanha.

## Papéis

Componentes usam **papéis, não números**. Cada peça declara o papel que cumpre; o preset decide quanto ele vale.

## Regras

**Aninhamento concêntrico.** Um elemento dentro de outro nunca tem raio maior que o de fora. Quando encosta na borda do pai, o raio de dentro é o de fora menos o espaçamento: por isso o item de menu usa `control` dentro de um menu `overlay`.

**O papel manda, não o tamanho.** Um botão grande continua `control`; um card pequeno continua `container`.

**`full` não é estilo.** Pílula só onde a forma comunica algo; nunca para "suavizar" um botão.

## Escala

A escala numérica (`xs` a `2xl`) existe para casos fora dos papéis; prefira sempre o papel.
